# রিপ্লে — Replay

তোমার নিজের কথা থেকে বানানো স্পিকিং ড্রিল। লক্ষ্য একটাই: **অতীত ঘটনা, হাইপোথেটিক্যাল
সিচুয়েশন আর লম্বা জটিল বাক্য** মুখে বসানো — রুল মুখস্থ করে নয়, রেপ দিয়ে।

প্রতিটা বাক্য তোমার VoiceInk ট্রান্সক্রিপ্ট থেকে নেওয়া (৪৬৬ রেকর্ডিং · ২০,১২৭ শব্দ)।
কার্ডে প্রথমেই তোমার আসল লাইনটা দেখবে, তারপর তার নিখুঁত রিপ্লে।

ডিজাইন ও ডায়াগনোসিসের পুরো যুক্তি: [PLAN-V3.md](PLAN-V3.md)

## ছয়টা স্টেশন

| স্টেশন | ড্রিল |
|---|---|
| ⏪ টাইম মেশিন | present-এ বলা ঘটনা ট্যাপ করে past-এ ফ্লিপ করো |
| 🪜 সিঁড়ি | ৫ শব্দ → ২৩ শব্দ, প্রতি ধাপে এক clause |
| 🧵 উল্টো গাঁথা | বাক্যের লেজ আগে, তারপর সামনে জোড়া |
| 🧩 ছাঁচ | এক প্যাটার্ন, পাঁচ ভরাট (অফিস + দৈনন্দিন) |
| 🌀 যদি-মেশিন | আসল ঘটনা → `would have` ভার্সন |
| 🎤 বস | একই গল্প ৬০ → ৪৫ → ৩০ সেকেন্ডে |

প্রতিটা টার্গেট বাক্যে 🔊 অডিও (ব্রাউজারের স্পিচ ইঞ্জিন), ০.৭৫× / ১× / ১.২৫× গতি,
আর যে শব্দটা বাজছে সেটা হাইলাইট হয়।

## কনটেন্ট

এখন **১১টা সেট · ১৩৪ কার্ড · ~৬৩৯ রেপ** — পাঁচটা ওয়ার্ল্ডে দুইবার করে ঘোরে:
স্ট্যান্ডআপ রিপ্লে → টাইমলাইন → পোস্টমর্টেম → প্রপোজাল → মিটিং বস।
প্রতিটা সেটে অফিস আর দৈনন্দিন — দুই স্বাদই আছে।

নতুন কনটেন্ট প্রতি মাসে তোমার নতুন VoiceInk এক্সপোর্ট থেকে তৈরি হয়:

```bash
python3 tools/mine.py ~/Downloads/VoiceInk-transcription.csv -o tools/briefs.json
# tools/authored.json-এ ভাষাটা লেখো
python3 tools/build_sets.py tools/authored.json -o content/
python3 tools/validate.py
```

পুরো পদ্ধতি [tools/README.md](tools/README.md)-এ। স্কিমা `3.1` — [PLAN-V3.md](PLAN-V3.md) দেখো।
সেট নম্বরে ফাঁক রেখো না; অ্যাপ প্রথম ফাঁকেই খোঁজা থামায়।

> **তোমার ট্রান্সক্রিপ্ট রিপোতে যায় না।** `tools/*.csv` আর `tools/briefs.json`
> git-ignore করা — এই রিপোজিটরি পাবলিক, আর ওখানে ক্লায়েন্ট ও অভ্যন্তরীণ তথ্য থাকে।

## প্রগ্রেস

ব্রাউজারের `localStorage`-এ (`eng30:v3:*`)। হোম থেকে **ব্যাকআপ** দিয়ে
`replay-progress.json` নামিয়ে রাখো, **ফেরাও** দিয়ে অন্য ডিভাইসে নাও।

### মাঝপথে থামলে

একটা সেট ১২–১৪ কার্ড, আর এক বসায় পুরোটা শেষ না-ও হতে পারে। **প্রতিটা কার্ড শেষ
হওয়ার সঙ্গে সঙ্গে** যেখানে আছো সেটা `eng30:v3:progress`-এ জমা হয় — কোন কার্ডগুলো
কোন ক্রমে বিলি হয়েছিল, কত নম্বরে ছিলে, আর এতক্ষণের পয়েন্ট, রেপ ও ফ্লুয়েন্সি।
অ্যাপ বন্ধ করলে বা ট্যাব হারালে কিছু যায় না।

ফিরে এলে হোমের একদম উপরে **যেখানে থেমেছিলে** কার্ডটা থাকে — *চালিয়ে যাও* চাপলেই
সেই একই ডেক, সেই একই ক্রমে, ঠিক পরের কার্ড থেকে শুরু। সেট ম্যাপে অর্ধেক হওয়া
টাইলের নিচে একটা ভরাট লাইন দেখায় কতটা বাকি। শুরু থেকে খেলতে চাইলে কার্ডের উপরের
**শুরু থেকে** বোতাম আছে। সেট শেষ হলে চেকপয়েন্ট নিজেই মুছে যায়।

রিভিউ আর মিক্সড ড্রিলও একইভাবে ফিরে পাওয়া যায়। চেকপয়েন্ট ব্যাকআপ ফাইলেও যায়, আর
৪৫ দিনের পুরনো হলে বাদ পড়ে।
